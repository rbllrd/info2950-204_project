## Submission Checklist

To receive credit for Phase I, the submission must include the following:

- A link to your group's project workspace (a Git repository, Deepnote, or Google Colab), with your mentors given access
- Three ideas for datasets. For each idea, include:
  - A short description of the dataset.
  - A short discussion of the availability of the data
    - You must include links to online data sources, and each idea must be sourceable through API access, web scraping, or a combination of at least two meaningfully distinct public datasets. It is acceptable to include:
      - Link(s) to already formatted data (i.e., data you can download directly).
        - A single downloadable dataset does not meet the requirement on its own. Link at least two meaningfully distinct public datasets and briefly describe how you would combine them: what shared unit of observation or key you would join on (e.g. county, player-season, date), and what the combined data lets you ask that neither source answers alone.
      - Link(s) to websites from which you intend to collect data. If you intend to collect data, you must also include a brief description of how you plan to collect the data. For example:
        - Will you use an API? If so, please make sure to discuss whether you need an API key and whether the API will cost money to use (we recommend that you use free APIs)
        - Will you scrape the data? If so, please make sure to confirm whether the website allows web scraping.
  - A short discussion of the trustworthiness of the data. This might include:
    - Who collected the data? Do you trust this source? Why? If you plan to combine two or more datasets, answer this for each source.
      - If the dataset you are using was published (for example, in an academic paper or a government report), make sure to cite that publication as part of your discussion.
    - How were the data checked for quality? Do you have any concerns about the accuracy of the data?
- Questions for reviewers
